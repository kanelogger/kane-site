## Project overview

Report Archive collects standalone HTML reports and self-contained interactive report sites behind one chronological index. A Node.js script scans the report directory and regenerates the landing page, while GitHub Actions deploys the static files to GitHub Pages.

Visit the [live archive](https://kanelogger.github.io/my-reports/) or inspect the [public repository](https://github.com/kanelogger/my-reports).
