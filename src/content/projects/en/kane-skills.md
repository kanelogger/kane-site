## Project overview

Kane Skills packages recurring Agent workflows as standalone skills. Each package includes a `SKILL.md` and any scripts, assets, or references the workflow needs.

Browse the [English skill catalog](https://kanelogger.github.io/kane-skills/en/#catalog) by category or search by name, use case, or deliverable. The workbench shows source material and sample outputs for selected skills. Each skill page describes what it does, what it produces, and what you’ll need, with a copyable install command and links to the source.

Read the [Chinese project page](/work/kane-skills) for more about the library.
