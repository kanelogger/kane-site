## 项目概览

Kane Skills 把经常用到的 Agent 工作流整理成独立的技能包。每个技能都包含 `SKILL.md`，并按需附带脚本、素材或参考资料，可以单独安装和修改。

目前公开的 23 个技能分为阅读与解读、创作与成文、文稿加工与审校、素材获取与处理、内容发布、需求探索与选型、开发维护与交付七类。比如，可以用 `article-analyzer` 拆解长文，用 `kane-explainer` 制作视觉解释，或用 `kane-post-to-wx` 准备公众号稿件。

## 查找与安装

[技能目录](https://kanelogger.github.io/kane-skills/#catalog)支持按分类浏览，也能按名称、用途或交付物搜索。工作台展示部分技能的原始材料和产物示例，方便在安装前判断它是否适合手头的任务。

技能详情页列出适用场景、交付物、运行前准备和 GitHub 源码，并提供可以复制的单技能安装命令。技能包采用 [MIT 许可](https://github.com/kanelogger/kane-skills/blob/main/LICENSE)。
