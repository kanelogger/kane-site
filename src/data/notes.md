总结了下我现在是如何获取参考建议的：

1. 现阶段能用到的最强的模型，推理开到最高。
2. X 上让 Grok 基于 X 的内容给出建议。

比如这个问题：现阶段写代码的workflow是否仍旧是 PDCA？
先去问 GPT/Claude，省一点 token 可以用网页端。然后再去 Grok 提问：现阶段写代码的workflow是否仍旧是 PDCA？请你基于 X 上的内容给出建议。

这样你就能获得一份比较完整的更有参考价值的建议材料。
