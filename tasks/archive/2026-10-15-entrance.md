## 决定与依据

- 采用炭黑、暖白、朱红的独立视觉方向，巨幅 KANE 字标与原创线束雕塑共同构图。
- 原创参数曲线在 Canvas 中进行 3D 投影；本地 SVG 作为静态回退。无新增依赖和第三方媒体请求。
- 仅每标签会话首次直接访问无锚点首页时自动出现；文章直达、客户端返回首页和历史返回不拦截，首页保留重播与原 GitHub 入口。
- 原生 dialog 负责焦点与背景隔离，服务端默认关闭；增强模块失败时内联跳过仍可用。
- 自动动态约 3.6 秒后停止调度；指针反馈按需绘制，支持暂停、隐藏文档停绘和减少动态效果。
- 构建校验允许明确标注 `role="presentation"` 的装饰图使用空 alt；缺失 alt 仍失败。新增默认开启 dialog 的负向回归，防止无 JavaScript 被遮挡。
- 参考 [Webby 官方评审维度](https://www.webbyawards.com/judging-criteria/)：内容、结构、视觉、功能、交互和整体体验。Awwwards/FWA 官方细则本次未成功提取，不杜撰权重或评审分数。
