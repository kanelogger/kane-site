# 首页设计切换

Status: complete
Updated: 2026-10-17

## 目标与验收

- 现有首页增加切换入口，点击进入工作台设计页面；新页面提供返回入口。
- 路由与本地资源进入 Astro 构建，桌面和移动均可操作，无 JavaScript 时仍可切换。

- 基线：`0e22ba4`；开始时工作区干净。
- 独立稿已存在于 `designs/kane-workshop/`。
- 本任务：新增 `/workshop` 路由、正式资源与样式脚本，首页增加切换链接。
- 已完成：构建与部署产物验证、桌面与手机双向切换、键盘 Enter、禁用 JavaScript 的完整往返。
- 阻塞：无。

## 决定与依据

- 两套首页用原生链接和完整页面导航切换，保持独立样式与监听器生命周期，避免全局样式互相污染。
- 生产源码与插图复制到正式目录，构建不依赖设计稿目录；项目封面复用现有公开资源。
- 本轮不更改默认首页，不推送或部署。
