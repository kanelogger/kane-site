# Kane 的工作台 · 首页设计探索

状态：待用户审阅。独立设计稿，未接入 Astro 生产路由。

## 设计依据

- 参考用户提供的《我们凭感觉敲出来的网站，看着像设计师做的》正文，原作者 Yakko Majuri；[原文](https://railcode.dev/blog/vibe-coded-website)。本轮使用提供的文章副本，未独立核验原站当前版本。
- 采用其中的设计方法：选一个具体视觉概念，向整页延伸；让区块颜色连接内容；保留配色试验入口。
- 将概念转为 Kane 自己的“造物工作台”：工具柜、模块与连接小径呼应开发者工具和工程实践。插图为本轮原创生成，没有复制参考站素材。
- 文案依据：`src/data/site.ts`、现有首页与 Skill Port、QuotaBar、Kane Skills 项目内容，以及三篇精选文章。没有新增项目能力、用户数量或发布承诺。
- 字体使用系统字体；所有图片保存在当前目录，运行时没有外部资源请求。

## 文件与预览

- 入口：`index.html`；样式：`workshop.css`；交互：`workshop.js`。
- `preview.png` 为桌面首屏截图。
- 可直接在浏览器打开 HTML；也可在仓库根运行 `python3 -m http.server 4311 --bind 127.0.0.1 --directory designs`，访问 `http://127.0.0.1:4311/kane-workshop/`。结束后用 Ctrl-C 停止。
- 鼠尾草、晴空蓝、暖纸白三个配色会影响页面与导航；插图保留原色，便于比较页面配色。
- 配色在可用时保存到本地存储。无脚本时显示完整正文和默认配色；存储受限时仍可切换配色。

## 图片来源

- `imgs/workshop.png`：通过内置 imagegen 生成。完整提示词保存在 `prompts/01-workshop.md`，核心描述为“以微缩建筑模型表现软件工程师的造物工作台，鼠尾草、陶土、黄铜与纸白，无人物和文字”。
- 其余三张项目封面来自本仓库对应项目素材，复制到本目录以便独立预览。

## 验收

- 桌面 1440 × 1000、手机 390 × 844：实际浏览器检查布局，无横向溢出。
- 三种配色、恢复默认、刷新保存、Escape 关闭面板、Tab 与跳到正文：通过。
- 区块锚点、导航背景与当前项目更新、页面历史返回：通过。
- 减少动态模式下滚动为即时，禁用 JavaScript 时四个正文区块完整可读：通过。
- 本地存储抛出 SecurityError 时配色切换仍可用：通过。
- 浏览器未捕获脚本错误；资源全部来自本地预览服务。
- `pnpm verify`：通过。此命令验证现有 Astro 网站；独立稿由上述浏览器检查覆盖。
