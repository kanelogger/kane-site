# 网络与文件系统

安装依赖需要包仓库网络与本机包缓存写权限。Node 安装还需要版本管理器使用的官方分发源；CI 下载 Actions 和工具链需要 GitHub 与对应分发源。仓库不硬编码代理、证书或本机缓存路径。

依赖安装完成后，构建及 `pnpm verify` 不需要线上站点或生产账号，但部署回归测试和 doctor 需要 loopback。`pnpm verify:deployment URL` 会读取给定地址的页面与资源，应仅传入本任务实际验收的地址。

日常写入限于本任务授权范围；生成物为 `node_modules/`、`.astro/`、`dist/`、临时 fixture 和 `.agent-local/`。实际沙箱可读写边界由当前会话决定。遇到 `EPERM`、`EACCES` 等错误，记录对应操作并按工具的授权机制处理，不能自行把文档中的允许写入视为系统许可。

以下内容不进入公开 Git 文件、网页或任务摘要：密钥、生产凭据、私有素材来源、本机绝对路径和未公开个人信息。继续忽略 `private-*.md`、`.agents/`、`DESIGN.md`、`.env*`（公开样例除外）和 `.agent-local/`。私有任务可在 `.agent-local/` 留存，但跨机器恢复时须由用户提供，不声称 Git 能同步它。

外部写入、发布、生产变更与破坏性操作要求用户明确授权；已有授权在本次任务范围内持续有效。正常本地可逆修改和验证按开发任务授权执行。
