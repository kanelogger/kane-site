# 说说

公开内容统一保存在 [src/data/notes.md](../src/data/notes.md)。页面为 `/notes`，英文界面为 `/en/notes`；两者展示相同原文，不自动翻译。

## 录入

每条以二级日期标题开始，时间按北京时间（UTC+08:00）解释。推荐填写到分钟，同一分钟只保留一条；只写日期时按当天 00:00 处理。页面自动按时间倒序展示，文件内可以按任意顺序编写。

```markdown
## 2026-11-01 15:30

这里写正文，支持 **强调**、链接、列表和引用。

![图片的实际内容描述](/assets/notes/2026-11-01/coffee.webp)

## 2026-11-01 18:20

另一条说说。
```

图片文件放在 `public/assets/notes/` 下，推荐按日期建子目录。正文使用 `/assets/notes/…` 路径，必须填写图片描述；支持多张图片，保留完整比例并按正文顺序显示。不支持外链图片或本机绝对路径。代码块中的日期标题和图片语法只作为示例展示，不会拆成新条目或加载图片。

日期和时间不能重复或无效，正文不能为空。条目内部的小标题使用三级或更深的标题；二级标题保留给日期。修改条目的日期或时间会改变其页面锚点。空文件会显示“还没有说说”。

这里保存的全部内容都会参与公开构建；不要写入私密草稿、凭据或平台发布状态。

## 验证与上线

运行 `pnpm verify`，检查日期、图片、静态页面和回归结果；本地预览见 [服务](agent-environment/services.md)。验证通过后仍需提交并按项目发布流程部署，修改文件不会立即更新线上页面。说说不进入现有文章 RSS。

本模块只负责站点展示，不包含浏览器录入后台或社交平台发布 Skill。
